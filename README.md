## Abrir el proyecto
1. Clonar el repositorio (GitHub Desktop › Clone).
2. Ejecutar una vez `Herramientas/configurar-git-windows.bat` (o `configurar-git-mac.sh`).
3. Unity Hub › Add › Add project from disk. Versión de Unity: **6000.0.__f_** (poned la exacta que uséis los dos).
4. Escena principal: `Assets/_Juego/Escenas/…`

## Dónde está cada cosa
| Carpeta | Qué hay |
|---|---|
| `Assets/_Juego` | Nuestro juego: escenas, prefabs, scripts, arte, audio |
| `Assets/VRKit` | Kit de bloques VR (no se edita: se hereda o se copia a `_Juego`) |
| `ArtSource` | Archivos de Blender y fuentes de texturas (no los lee Unity) |
| `Docs` | Guías, GDD, notas |
